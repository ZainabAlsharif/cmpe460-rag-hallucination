# Report

- `main.tex` — the course template (`template460.tex`), one chapter per student + shared Introduction.
- `styles/ibu-thesis.sty` — course style file (do not edit).
- `references.bib` — shared BibTeX file. To use it, switch `main.tex` from `thebibliography` to `\bibliography{references}`.
- `figures/` — plots and diagrams for the report.

⚠️ The title page needs `figures/LOGO.png` (the university logo from the original template package). Add it before compiling.

Easiest workflow: upload this folder to **Overleaf**, share the Overleaf project with the group, and copy final figures back here.
Build file outputs (`.aux`, `.pdf`, …) are git-ignored.
